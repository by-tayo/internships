# Geospatial Data Analyst Intern

**Organization:** The University of Texas at Austin, Institute of Geophysics
**Program:** NASA MUREP PEMS, through LEAPS at Laredo College
**Dates:** Summer 2023

## Summary

Worked with airborne ice-penetrating radar data from Antarctica. Traced ice layers in radargrams and wrote Python code to build radargrams from raw radar data files.

## Tools

- Python (NumPy, Matplotlib, xarray, netCDF4)
- Red Hat Linux
- QGIS
- NetCDF Viewer

## What I did

1. Learned how airborne radar builds profiles of an ice sheet, showing the surface, internal layers, and bedrock.
2. Opened radar flight lines from a Linux terminal and switched between radar channels.
3. Traced the ice surface and bed across several radargrams from different regions.
4. Worked around gaps where the radar did not capture the ice below.
5. Opened raw radar data stored in NetCDF files using Python.
6. Wrote Python code to build grayscale radargrams at low and high gain.
7. Extracted key fields from each file, such as time, position, altitude, and amplitude.
8. Compared the Python results against QGIS and NetCDF Viewer to verify the output.
9. Removed sensitive details, such as locations and flight times, from my write-up.
10. Documented the methods, results, and limitations in a research report.

## Skills

Python · Scientific data formats · Image processing · Linux · Data verification · Research
